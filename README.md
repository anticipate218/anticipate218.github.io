# 曹帅帅 · Academic Homepage

个人学术主页源码，部署于 GitHub Pages：<https://anticipate218.github.io/>

Source of my academic homepage, deployed on GitHub Pages.

## 特性 / Features

- **中英双语**：右上角一键切换，记住选择；也支持 `?lang=en` / `?lang=zh`。
- **四套主题 + 跟随系统**：星穹 Celestial、晴空 Daylight、极光 Aurora、纸本 Paper；支持 `?theme=aurora`。
- **微动态**：仿 readme-typing-svg 的打字动画、地球轨道 SVG 与环绕卫星、头像轨道卫星。
- **星空背景**：tsParticles（CDN），CDN 不可用时自动切换到内置 Canvas 星空。
- **科研数据可视化**：交互式等距贡献日历（实时数据）、lowlighter/metrics 等距日历（GitHub Action 生成）、单篇引用条形图、研究方向与项目语言分布。
- **al-folio 式内容结构**：关于 / 动态 / 代表作 / 论文（按方向筛选、按年份分组、一键复制 BibTeX）/ 开源项目（Star 实时刷新）。
- **无构建步骤**：纯 HTML + CSS + JS，所有内容集中在 `assets/js/data.js`。
- 尊重 `prefers-reduced-motion`，并提供手动「动画」开关。

## 目录 / Structure

```
index.html                 页面结构 / markup
404.html                   404 页面
assets/css/style.css       样式与主题变量 / styles & theme tokens
assets/js/data.js          全部内容（个人信息、论文、动态、项目）/ all content
assets/js/i18n.js          界面文案 / UI strings
assets/js/viz.js           等距日历与图表 / isometric calendar & charts
assets/js/main.js          交互逻辑 / behaviour
assets/img/                avatar.jpg、bg.jpg、favicon.svg
metrics/isocalendar.svg    由 GitHub Action 生成 / generated by the Metrics workflow
tools/serve.mjs            本地预览服务器（零依赖）/ zero-dependency preview server
tools/prepare-images.ps1   从 photo.png / bg.png 生成网页图片 / image optimisation
.github/workflows/metrics.yml  lowlighter/metrics 等距日历
```

## 本地预览 / Local preview

```bash
node tools/serve.mjs        # → http://localhost:5173/
```

## 更新内容 / Updating content

- 论文、动态、项目：编辑 `assets/js/data.js`。
- Scholar 指标（引用数、h 指数）：修改 `scholar` 字段与 `meta.syncedAt`。
- 邮箱：在 `profile.email` 填入后，个人卡片会自动显示「邮箱」行与复制按钮。
- 替换头像或背景：覆盖根目录的 `photo.png` / `bg.png`，然后运行
  `powershell -ExecutionPolicy Bypass -File tools/prepare-images.ps1`。

## lowlighter/metrics 等距日历

1. 创建经典 Personal Access Token（勾选 `read:user`、`public_repo`）。
2. 在仓库 *Settings → Secrets and variables → Actions* 中新增 `METRICS_TOKEN`。
3. 在 *Actions → Metrics* 中手动运行一次，之后每天自动更新 `metrics/isocalendar.svg`。

未配置 Token 时工作流会自动跳过，主页仍显示交互式等距日历。
